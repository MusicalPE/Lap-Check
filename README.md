# 실험첵! Lab-Check!

초등 과학 실험 수업 도우미입니다.

- 선생님이 실험을 고르고 QR을 띄우면, 학생들이 각자 기기로 들어와 조를 고릅니다.
- 학생 화면은 준비 → 1단계 → 2단계 → … → 결과 순서로 한 장씩 넘어갑니다.
- 조마다 "다했어요"를 누르면 선생님 화면에 모이고, 모든 조가 끝내면 선생님이 다음 장을 엽니다.
- 학교에서 쓰는 교과서를 골라 두면 실험마다 교과서 쪽수가 함께 보입니다.

지금 들어 있는 실험: 2022 개정 교육과정 5학년 1·2학기 (8개 단원, 29개 실험)

## 설치

`설치 방법.txt`와 `파이어베이스 규칙.txt`를 보세요.
`firebase-config.js`가 비어 있으면 그 기기 안에서만 돌아가는 체험 모드로 열립니다.

LICENSE 파일을 보세요. 교육 목적으로는 자유롭게 쓸 수 있고, 상업적 사용과 허락 없이 고쳐서 다시 배포하는 것은 금지합니다.
